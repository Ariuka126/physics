# AS Physics Masterclass & Lab

    npm install
    npm run dev      # http://localhost:3000

Structure: `lib/physics-data.ts` (single source of truth for the archive and the equation table), `components/` (Archive, ReferenceTable, CircuitLab, Tex), `app/` (routes: /, /archive, /reference, /lab).
